# attn 复杂度：原理性测定方案

> 目标：把「1 次 + 2 次」这类多项式拟合换成**能被证伪的机理模型**，并给出定位真实复杂度所需的测量。
> 前置事实（已由现有数据确立）：
> - 同一批 39 点上，`b + A·L^1.5 + B·L^0.5`（7.41%）比 `b + θ₁L + θ₂L²`（8.51%）更好 ⇒ 精度不由形式决定。
> - 可信点（`T−b > 3σ`）仅 12 个，L 只跨 4 倍，小段 6 点信噪比 < 1。
> - 13 个点全落在 128 的块格上，`ceil` 无投票权。
> - 实测每块 7.5 μs，roofline 下界约 31 ns，差 240 倍——**假设一定有错，但多项式把它吸收掉了**。
>
> 因此本方案的核心不是「多取几个 L」，而是**把 b 与计算项分开、把两个 GEMM 分开、把取整显形**。

---

## 〇、三件事必须先做，否则后面的数据不可用

| # | 问题 | 现状 | 做法 | 成本 |
|---|---|---|---|---|
| P1 | **同点重复噪声未知** | 点间离散度 11.5%（含真实差异），**同点重复噪声从未测过**；而 E3 的可行性与 E5 的判据全依赖它 | 取 3 个代表性点（小/中/大 L），每点连测 **10 次**，报中位数 ± IQR | 3 点 × 10 次 |
| P2 | **`b` 从未独立测过** | `b` 一直由拟合给出（8.80/10.71/12.32），因此「b 随 N 上升」本身可能是拟合伪影 | 用「层数倍比」与「空 kernel」两条路独立测 `b` | 4 + 2 次 |
| P3 | **时间口径不明** | 未说明是否每次迭代 `synchronize`、是否 flush L2 | 固定协议：warmup 1 次 + 计时 N 次取中位数；每次计时前 `torch.npu.synchronize()`；不 flush（线上也不 flush） | 0 |

**P1 是门，不是准备步骤。** 它决定后面几个实验能不能做：

| 若同点噪声为 | E3（台阶）的 S/N | E5（`L*`）可分辨的斜率差 | 结论 |
|---|---|---|---|
| 2% | 6.9 | ±0.03 | 全部实验可做 |
| 3% | 4.6 | ±0.05 | 全部可做 |
| 5% | 2.7 | ±0.08 | E3 勉强，建议放弃 |
| 11.5% | 1.2 | ±0.19 | **E3 必须放弃**，E5 只能定 L* 到 2 倍误差 |

所以**先花 30 次测量把 P1 做掉，再决定 E3 做不做**——而不是先做 E3 再发现测不出来。

## 一、五个决定性实验

### E1　`b` 的三分：下发、同步、通信轮次

**问什么**：`b` 是不是 `n_kernel · c_dispatch + n_sync · t_sync + n_round · α`？

**怎么测**（三组，互不依赖）：

| 组 | 构造 | 只改什么 | 判据 |
|---|---|---|---|
| E1a | 同一注意力层，堆 `n_layers = 1 / 2 / 4` | kernel 数 | `b` 是否严格 ∝ 层数（斜率即 `c_dispatch`） |
| E1b | 同一层，去掉每次迭代的 `synchronize` | 同步次数 | `Δb` 即 `t_sync` |
| E1c | 固定 L、固定层数，扫 N = 1/2/4/8 | 通信轮次 | `b` 的增量是否呈阶梯（Ring：+1 轮/档；非 +N） |

**成本**：3 + 2 + 4 = 9 次请求。
**输出**：`c_dispatch`（μs/kernel）、`t_sync`、`α` 三个有单位的常数，`b` 从此不再拟合。

> 若 E1a 显示 `b` 与层数不成正比，则 `b` 里还有与 L 无关但非下发的成分（如未切分 KV 的常驻搬运），需要单列。

---

### E2　两个 GEMM 分开：`qkᵀ` 与 `p·v`

**问什么**：L² 项的宽度到底是 `d_head` 还是 `d_head + d_v`？（HSTU 核对给出的是后者，但只在一种配置上验证过）

**怎么测**：构造 `d_head ≠ d_v` 的注意力 kernel，取三组：

| 组 | `d_head` | `d_v` | `qkᵀ` FLOPs ∝ | `p·v` FLOPs ∝ |
|---|---|---|---|---|
| A | 64 | 64 | 64 | 64 |
| B | 128 | 64 | 128 | 64 |
| C | 64 | 128 | 64 | 128 |

固定 `B·H·L²`，比较三者时间。

**判据**：

- 若 `T(A) : T(B) : T(C) = 1 : 1.5 : 1.5` ⇒ 两个 GEMM 等权，宽度 = 平均值 ⇒ **`d_head + d_v` 正确**
- 若 `= 1 : 2 : 1` ⇒ 只有 `qkᵀ` 计费（不合理，PV 也是 L²）⇒ 说明 `p·v` 走了另一条路（如分块累加被融合）
- 若 `= 1 : 1 : 1` ⇒ L² 项与头维无关 ⇒ **说明瓶颈根本不是 GEMM**，是别的（如 softmax 或调度）

**成本**：3 次请求（若模型不支持改头维，改用独立 kernel 微基准）。
**输出**：确认或推翻 `value_dim` 登记项；若为第三種，直接改写整个模型的物理前提。

---

### E3　取整显形：台阶是否存在

**问什么**：块数 `ceil(L/BM) × ceil(L/(N·BM))` 的台阶，在时间上是否可见？

**为什么这一节要重写**：按信噪比算过之后，原本设计的 cp2/8192 组是**不可测的**——块数只跳 1.5%，低于任何可达到的噪声。必须选「块数的相对跳幅大」且「计算项占比高」的格子。两列同时看：

| 组 | N | L 取值 | 块数 | 相对跳幅 | 计算项占比 | 单对 S/N（σ=2%） |
|---|---|---|---|---|---|---|
| 原设计 | 2 | 8192 / 8320 | 2048 → 2145 | +4.7% | 61% | 0.8 |
| **改用** | **8** | **8192 / 8320** | **512 → 585** | **+14.3%** | **27%** | **6.9** |

差异来源：`ceil(L/N/BM)` 在小 `N` 之上被放大。cp8 时 `L/N = 1024`，8320 让它从 8 块跳到 9 块（+12.5%），乘上 KV 侧 64→65 块，合计 +14.3%。

**怎么测**：

| 组 | 取值 | 只改什么 |
|---|---|---|
| E3a | `N=8`，L = 8192, 8320, 8448 | KV 与 Q 两侧各跳一次 |
| E3b | `N=2`，L = 8192, 8256, 8320 | Q 侧块数 32/33/34，用于区分两侧的基本块 |

每组每点重复 **10 次**（不是 5 次：E3 是全表里信噪比最紧的一项）。

**判据**（逐对比较，S/N < 3 的对不参与判定）：

- 可判的对全部与块数比一致 ⇒ 台阶成立，`ceil` 进模型
- 出现冲突 ⇒ 台阶不成立，`ceil` 删掉，改回 `L²/N`
- 全部 S/N < 3 ⇒ **判为不可测**，说明 P1 没做到位，不是「没有台阶」

**成本**：6 次请求 × 10 次重复。
**依赖**：**必须先有 P1 的同点噪声数**。若同点噪声真有 11.5%，E3 的一切结论都无效（S/N 会降到 1.2）。

---

### E4　并行结构：外循环是否并行于核

**问什么**：`B·H` 是「全部 tile 一起分核」还是「外循环（head/query）分核、内循环（KV）串行」？两者的复杂度差别很大。

```
方案 I （全 tile 并行）：N_work = B·H·ceil(L/(N·BM))·ceil(L/BN)
方案 II（外循环并行）  ：N_work = ceil(B·H·ceil(L/(N·BM)) / C) · ceil(L/BN)
```

**怎么测**：固定 `L`、`N`，扫 `B·H`：

| 组 | `B·H` | 只改什么 |
|---|---|---|
| E4 | 1, 2, 4, 8, 16, 32 | 可并行的 tile 数 |

**判据**：

- `T` 随 `B·H` **严格线性** ⇒ 方案 I（tile 无限可分）
- `T` 随 `B·H` **阶梯**上升，台阶在 `C, 2C, 3C` ⇒ 方案 II，且**台阶间距直接给出核数 `C`**
- `T` 在 `B·H < C` 时**完全平坦** ⇒ 存在「不足一波」的平台，这解释小 L

**成本**：6 次请求。
**输出**：`C`（核数）与并行结构二选一。这两个数决定过渡点 `L* ∝ √(C·N/(B·H))`。

---

### E5　regime 切换点：`L*` 在哪

**问什么**：从「访存 bound（∝L）」转到「计算 bound（∝L²）」的拐点位置，是否与 `2P·η/BW` 相符。

**怎么测**：单层、`N=1`、`B=1`、固定 `H`，扫 `L` 覆盖 256 → 65536（等比 12 档），对数-对数画图求局部斜率。

**判据**：

- 斜率从 ≈1 过渡到 ≈2，过渡中点即 `L*`
- 理论 `L* = 2P/BW`：910B3 约 **153**（若带宽 1.6 TB/s）或 **1250**（若 392 GB/s）
- 实测 `L*` 若远大于两者 ⇒ 有效带宽/算力远低于标称，`η` 可反解：`η = L*_实测·BW / (2P)`

**成本**：12 次请求（单层转发，最便宜）。
**为什么必须 `N=1`**：现有数据全是 N≥2，切分把「每卡工作量」这层变量叠了上来，无法分离。

## 二、判据总表：数据 → 结论

测完之后按下表查，不需要主观判断。

| 观测量 | 取值 | 结论 | 对模型的影响 |
|---|---|---|---|
| E1a 斜率 | ≈ n_layers | `b` 是下发项 | `b = c_dispatch·n_kernel`，删掉 `intercept` 拟合列 |
| E1a 斜率 | ≠ n_layers | `b` 含常驻搬运 | 需按「计算段/固定块」分两类 |
| E1c 阶梯 | +1 轮/档 | Ring/Butterfly | `τ = s(N)·α`，`s` 登记 |
| E2 比值 | 1 : 1.5 : 1.5 | 两 GEMM 等权 | 保留 `value_dim` |
| E2 比值 | 1 : 1 : 1 | L² 项与头维无关 | **推翻 GEMM 主项**，改查 softmax/调度 |
| E3a 形状 | 阶梯 | 取整真实 | 保留 `ceil`，`BM/BN` 可辨识 |
| E3a 形状 | 平滑 | 取整无效 | **删掉 `ceil`**，改回 `L²/N` |
| E4 形状 | 线性 | tile 全并行 | `N_work` 用方案 I |
| E4 形状 | 阶梯 `C,2C,3C` | 外循环并行 | 方案 II，`C` 已知 |
| E4 形状 | 小 `B·H` 平坦 | 不足一波 | 引入 `max(1, ceil(·/C))` |
| E5 `L*` | ≈153 或 1250 | 达到标称 | `η≈1`，`c` 可由 roofline 直算 |
| E5 `L*` | ≫ 两者 | 远离标称 | `η = L*·BW/(2P)`，作为单一校准量 |

## 三、拿到数据后如何定位复杂度

四步，每步产出一个数；四步做完模型没有自由参数。

### 第 1 步：定 `b`（不拟合）

```
b(N, n_layers) = c_dispatch · n_kernel(n_layers) + t_sync + s(N)·α
```

从 E1 直接得。回头检验现有数据：`b` = 8.80 / 10.71 / 12.32 ms，**若层数相同**，则增量 1.91 / 1.61 ms 应全部来自 `s(N)·α`，即通信轮次差。

### 第 2 步：定主项形状

```
N_work = B·H·ceil(L/(N·BM))·ceil(L/BN)     ← E3 定 BM/BN 是否存在
     或 B·H·L²/(N·BM²)                     ← E3 判「平滑」时用这条
```

E4 决定是否再套一层 `max(1, ceil(N_work/C))`。

### 第 3 步：定每单位时间 `t_unit`

```
t_unit = max( 2·BM·BN·(d+d_v)/P_eff ,  (BM·d + 2·BN·d_v)·s/BW_eff )
```

`P_eff`、`BW_eff` 由 E5 的 `L*` 反解：

```
L* = 2·P_eff / BW_eff        （attention 的算术强度 = L，见附录）
```

再用 E2 定 `(d+d_v)`。**这一步之后 `c` 不再是自由参数。**

### 第 4 步：残差诊断

模型定型后，残差不应再有系统性结构。检查三件事：

- 残差 vs L：若中段仍拱起 ⇒ 有一个未建模的、随 L 增长但不 ∝L² 的项（最可能是 mask 跳过的实际比例 σ）
- 残差 vs N：若随 N 单调 ⇒ `s(N)` 或 `κ` 形式不对
- 残差 vs B·H：若随 `B·H` 呈锯齿 ⇒ 波次量化的 `C` 估错

**残差有结构 = 前提错，不是拟合不够。** 这是整个方案与多项式拟合的分界线：多项式永远能压平残差，机理模型不能，而正因如此它才能报错。

## 四、成本与优先级

| 实验 | 请求数 | 能推翻什么 | 优先级 |
|---|---|---|---|
| P1 重复测量 | 机时 ×5 | 一切「台阶」判据 | **最高** |
| E4 并行结构 | 6 | `N_work` 的形式、核数 `C` | 高 |
| E5 regime 与 `L*` | 9 | `η`、`P_eff`、`BW_eff` | 高 |
| E1 `b` 三分 | 7（含 N=1） | `b` 能否不拟合 | 中 |
| E3 台阶 | 6 | `ceil` 去留、`BM/BN` | 中 |
| E2 两个 GEMM | 3 | `value_dim`、甚至整个主项 | 低（但推翻力最大） |

合计 **31 次请求 + P1 的 5× 机时**，另需 2 次空 kernel 校准 `c_dispatch`（P2）。
若只能做一件事，做 **E4 + E5（15 次）**：它们能定出 `C`、`η` 与主项形状，而这三者决定了模型是「一个参数」还是「三个参数」。

## 四点五、代码入口

方案已落成代码，测量表与判定树都在里面：

```bash
cd 执行时间预测
python3 -m timepred.principle_demo     # 打印 31 条清单 + 判定树演示
```

| 模块 | 内容 |
|---|---|
| `timepred/principle.py` `experiment_plan()` | 31 条请求，按 E1a/E1c/E2/E3a/E3b/E4/E5 分组，可直接写成阶段测量表 |
| `identify_e1a / e1c / e2 / e3 / e4 / e5` | 六个判定函数，输入测量点，输出��论 + 置信度 |
| `infer_efficiency()` | 由 `L*` 反解 `P_eff` 与 `BW_eff` |
| `verdicts_to_model()` | 把六个结论翻成对模型的直接指令 |

判定函数只做「读数据 → 给可证伪的陈述」，不做模型选择。每个判据都用**两种相反输入**测过
（`tests/test_principle.py`，18 项）：同一条代码，喂阶梯数据必须说「台阶成立」，喂平滑数据
必须说「台阶不成立」，喂高噪声数据必须说「不可测」而不是「不存在」。

**三条设计原则**：

1. **不可测 ≠ 不存在。** S/N < 3 时判「不可测」，与判「无台阶」是不同结论。混淆这两者，
   会把「测不出」写成「没有」，这是最容易犯且最难发现的错误。
2. **相对判据，不用绝对阈值。** 所有比较都以「该点自身的相对抖动」为单位，避免大 L 点的
   绝对噪声把判据放宽。
3. **每个结论标注置信度。** 缺样本点报「无法判定」，不猜。

## 附录：attention 的算术强度为什么只由 `L` 决定

```
FLOPs = 4·B·H·L²·d          （qkᵀ 与 p·v 各 2 flops/乘加，各 B·H·L²·d 次乘加）
Bytes = 8·B·H·L·d           （Q、K、V、O 各一遍，fp16 每元素 2 字节）
强度  = FLOPs / Bytes = L / 2      （FLOP 每字节）
```

以 `B=1, H=8, L=4096, d=64` 验算：`3.436e10 / 1.678e7 = 2048 = L/2` ✓

令强度等于机器比值 `P/BW`：

```
L/2 = P/BW   ⟹   L* = 2·P/BW
```

| 口径 | `P` | `BW` | `L*` |
|---|---|---|---|
| 910B3 峰值 / HBM 1.6 TB/s | 245 TFLOPS | 1.6 TB/s | **306** |
| 910B1 / 1.6 TB/s | 295 TFLOPS | 1.6 TB/s | **369** |
| 若带宽为 392 GB/s | 245 TFLOPS | 392 GB/s | **1250** |

**结论：`L*` 与 `d`、`B`、`H` 全都无关，只与 `L` 有关。** 这是本方案里最硬的一条结构约束——若实测 `L*` 随 `d` 或 `H` 移动，说明主项不是 GEMM，第 2 步的前提就要推翻。

注意 `L*≈306` 远小于实测的漂移区间（4096 以上），比值约 13–27 倍。这个差距就是 `η` 的直接呈现，也是 E5 要量的东西。
